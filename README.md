# Blind Sensors: Transferring Satellite-Informed PM2.5 Models to Cities Without Monitors

Train PM2.5 models where sensors exist; transfer to sensor-sparse regions using satellite + meteorology features.

## This repository is independent
No shared code or data dependencies with the sibling environment papers.

## Quickstart
```bash
pip install numpy pandas scikit-learn matplotlib
jupyter notebook notebook/blind-sensors-pm25-transfer.ipynb
```

Or open the notebook on Kaggle and Run All.
